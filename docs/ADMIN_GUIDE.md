# Administrator Guide

## Recommended setup order

1. Complete Firebase setup and bootstrap the first administrator.
2. Ask students to sign in once so they appear in the user list.
3. Create and publish equipment courses.
4. Assign published courses to students.
5. Monitor progress from **Admin Overview** and **Students**.

## Student records

Open **Students** and select a learner. The record shows:

- assigned courses;
- current course completion percentage;
- number of completed lessons;
- every submitted quiz attempt;
- attempt score and pass/fail status.

Open an individual attempt to see the exact randomized questions that student received, the choices shown, the answer selected, the correct answer, and any explanation attached to the question.

## Administrator access

Users must sign in at least once before they can be promoted. Go to **Admin Access** and choose **Make admin**. Administrators can create/edit courses, assign training, review all student results, and manage other admins.

The UI blocks an administrator from demoting their own account. The first administrator can always be repaired from the Firebase Console if necessary.

## Archiving courses

Archiving hides a course from normal future use but does not delete student progress or quiz-attempt history. This is safer for school records than destructive deletion.
